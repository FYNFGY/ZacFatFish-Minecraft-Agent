# 01 — Ph9 范围与目标

## 1. 背景

Ph8 已证明以下能力：

- MCP Server / Bridge 生命周期
- 扫描、移动、挖掘、容器、GUI、聊天
- 近战/远程/逃跑/自卫
- 路径可达索敌
- Pendulum MCP 路由

但 Ph8 的“末地”测试主要依赖命令传送；真正原版生存所需的：

```text
找要塞 → 激活传送门 → 进入末地 → 清水晶 → 打龙
```

尚未闭环。

## 2. Ph9 目标（必须完成）

### G1 — 原版生存进入末地

- 从生存存档定位要塞
- 进入要塞并找到传送门房间
- 检查/补全 12 个末影之眼
- 激活传送门
- 进入末地，落在黑曜石平台

### G2 — 末地安全移动

- 不因走位/击退掉入虚空
- 不因爆炸/龙撞死亡
- 低血自动吃熟牛肉/撤退
- 至少能安全到达中央岛/水晶附近

### G3 — 水晶处理

- 查询所有末地水晶
- 区分铁栏杆保护/暴露水晶
- 从安全距离摧毁
- 记录剩余数量

### G4 — 末影龙战斗

- 识别龙本体（不是 EnderDragonPart）
- 识别 `perching` 窗口
- 在窗口内射击头部/身体
- 龙起飞时停火、举盾/躲避
- 玩家死亡/箭耗尽/长时间无伤害时返回结构化结果

### G5 — 可验证

- 所有 Ph9 新增工具进入 `MCP-TOOLS.md`
- 所有测试有 evidence JSON
- 所有 evidence 标注是否使用命令 setup

## 3. 非目标（Ph9 不做）

- 不实现完整多人服务器管理后台
- 不实现公开服务器外挂/自动 PVP
- 不把 Create/Apotheosis 的全部 GUI 做完
- 不保证所有模组整合包的末地维度都可用
- 不实现无限自动挂机/无人值守刷怪

## 4. 成功定义

### 最低成功

```text
生存进入末地（命令 setup 可用于测试，但需另列）
+ 清除至少 1 个水晶
+ 对龙造成有效伤害并安全撤退
```

### 完整成功

```text
生存进入末地
+ 清完水晶
+ 击杀末影龙
+ 返回 overworld 或明确记录返回失败
```

## 5. 里程碑

| 里程碑 | 内容 | 退出条件 |
|---|---|---|
| M9.1 | 要塞/传送门工具 | 能在生存存档定位并激活一个传送门 |
| M9.2 | 末地进入与安全 | 进入 End 后 60 秒不因虚空死亡 |
| M9.3 | 水晶 | 清掉至少 1 组水晶并记录 |
| M9.4 | 龙 | 至少一次 perch 有效伤害；完整击杀另评 |
| M9.5 | 回归/发布 | 全测试套件 + release + 文档 |

## 6. 约束

- Java 21 / Node.js 22
- NeoForge 1.21.1
- 客户端与 MCP 同机（当前架构）
- Pendulum/Baritone 可选
- 不新增需要公网端口的服务

## 7. 交付物

```text
代码：Bridge / MCP / 文档
工具：Ph9 新工具
测试：05-test-plan 的执行结果
证据：16-evidence-template 填写的 JSON
发布：09-release-checklist 通过的 release
```
